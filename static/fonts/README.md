# Fonts

The design uses two custom typefaces. Drop the font files here with these exact
filenames so the `@font-face` rules in `src/app.css` resolve them:

- `PixelHackers.woff2` — the page title ("just a purdue hackers QR code generator")
  and the "check out da github" link.
- `PolySans-Relax.woff2` — section labels ("Enter QR code data", "Settings").
- `PolySans-Neutral.woff2` — small option labels ("transparent bg", "color",
  "Need an API?").
- `PolySans-NeutralItalic.woff2` — the textarea placeholder ("mrrow mrrp meow").

Until these files are added, the page falls back to system fonts.
